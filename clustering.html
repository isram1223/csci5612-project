Clustering

Added in Project Part 2.

Overview

Clustering is an unsupervised machine learning technique used to discover inherent groupings within unlabeled data based on feature similarity. In this project, it is used to identify distinct community profiles based on 35 structural socioeconomic and health variables without referencing birth outcomes. Two methods were applied: partitional clustering (K-Means), which iteratively assigns counties to discrete groups by minimizing Euclidean distance to a central centroid, and hierarchical agglomerative clustering, which builds a bottom-up tree mapping nested relationships using cosine distance.

Prepared dataset: clean_unlabeled_numeric.csv. Raw data: raw_data folder.
